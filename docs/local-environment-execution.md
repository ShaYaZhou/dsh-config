# 本地环境与最近文件夹（R5）

桌面侧栏底部的 **本地环境**，或 **设置 → 本地环境**，使用同一管理界面。普通文件夹可直接打开；多个仓库、worktree 选择和变量名可保存成环境。选择 **在新会话中使用** 后创建独立会话，不提交或转移原草稿；**返回原会话** 可回到本次启动来源。该返回引用只保留最近一次启动来源，卸载时释放。

编辑环境时为每个仓库选择当前目录，或从本地分支、标签、提交创建独立 worktree。当前目录模式不会切换分支；worktree 不复制源目录未提交改动。先保存定义和本机目录，再按需展开 **本机变量**，每行填写字面量 `KEY=value`，支持空值，不执行表达式。已有值不回显；替换或清空会影响该环境所有会话的后续执行。

**导出定义** 下载 JSON；可将它纳入自己的 Git 仓库。导出不带本机路径或变量值。其他电脑安装此配置仓库后，导入 JSON，再重新绑定目录、配置变量。相同标识的导入更新定义，保留本机绑定和变量；缺少绑定或必需变量会在启动前拒绝。清空目录并保存会真正解绑。移除定义保留既有会话、worktree 和本机数据，不自动删除历史或分支。

## 当前契约

- 会话选择使用原生 `appendPluginRecord` 写入 `plugin:local-environments/selected`，并由 projection 读取。记录可忽略，卸载/回滚插件后原生读取器仍能读取历史。记录只含名称、仓库目录等元数据；环境值不进入选择记录或首次模型上下文。
- 变量保存在原生凭据服务的插件自有 `grant` record，每次执行重新读取，支持空字符串。原生存储是文件，不能宣称加密。
- 原生 PowerShell 沙箱执行器与原生 PTY provider 通过薄子类接入；普通同步 spawn 不变，不修改宿主 `process.env`。
- 拒绝 `DSH_*`、非法变量名、Windows 大小写重复、NUL 和超限输入。Windows 必需变量按大小写不敏感检查，POSIX 精确匹配。
- 已选环境的原生 subagent 或 linked family 子会话继承选择；没有选择的无关会话不受影响。
- 适配器必须以新 Cordis row 插入并禁用原 row，`name` 不是重命名字段。验收首先断言实际运行类，避免未加载适配器的假验证。
- 定义、本机绑定属于环境插件自己的原生 storage domain，变量值属于原生凭据服务；无 Agent 工具可改变这些配置。所有管理 Remote 接口只允许 owner。
- 预检所有目录、Git ref 和必需变量后才调用原生 worktree 服务。准备会话只做工作区创建，成功后归档；失败保留已有产物和可追查的会话编号。主会话与各仓库子会话保留各自的原生沙箱根目录，不扩大到公共父目录。
- 在 Git 未启用长路径支持的 Windows 深目录中，原生 worktree 可能失败；错误会保留产物并提示显式配置该仓库的 `core.longpaths=true` 或改用较短路径，不自动改全局 Git 设置。

## 本次运行证据

2026-10-21，DSH 0.2.1-rc.2、Windows 原生宿主、隔离 DSH_HOME、已配置的 LLM proxy：

- 两个真实并发模型会话分别调用 `pwsh`，读到不同测试值及各自 `DSH_SESSION_ID`，权限保持 `read-only`。
- 首次 provider 请求未包含测试值；选择事件未包含测试值。工具主动输出值后会进入本次工具记录，这是正常工具结果，并非凭据自动注入上下文。
- 无环境会话没有获得变量，更新变量后下一次执行读到新值，原生凭据服务保留空值。
- 原生交互 PTY 读到本会话值，随后显式 terminate 并等待 done，再关闭 runtime、释放测试租约。一次性验收宿主在 stdout 刷新后退出；失败路径也在清理和释放租约后退出 1。
- 测试先核实实际凭据 provider 的路径及 realpath 属于隔离文件，拒绝显式路径或链接重定向。
- 两个真实 Git 仓库创建了独立 worktree，提交内容、未提交源文件和排除文件均按实际文件检查。第二个仓库的 linked session 继承环境变量，两个会话的沙箱 root 分别对应自己的 checkout。
- runtime 关闭后，不加载环境插件，仅用原生 persistence 打开保存的会话，确认选择记录可忽略且历史可读。隔离 home 的重新安装也通过。
- 原生前端已实际保存、解绑/重新绑定、变量更新、启动、返回草稿、下载定义及文件导入；下载 JSON 不含测试值/路径，导入后的缺失绑定明确阻止启动。实际截图保存在任务输出中，不提交个人路径或合成会话数据。

复现：先用仓库安装器准备隔离 home，再在本地提供 `OPENAI_API_KEY`，执行 `node scripts/harness.mjs environment-execution-test --home <isolated-home>`。不能对实际日常 home 运行 agent 验收。运行产物在 `.local`，不提交会话、凭据或个人路径。

执行层、catalog 和客户端检查覆盖参数边界、owner-only、变量隔离、继承/取消、便携定义、绑定隔离、启动预检、部分失败保留和导航引用释放。带未关闭 interval 的失败启动负例也确认退出码 1、测试租约释放，不能用进程挂住掩盖失败。

当前真实验收覆盖 Windows 桌面 composition、PowerShell 和 PTY；未验证其他操作系统或任何远程环境。后续任务建议（R6）属于下一阶段，不由本功能代替。
