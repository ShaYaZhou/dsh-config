# 无限画布接入 LiClick

需要 PATH 中的独立 Node.js、已安装并登录的 `atlas-skillhub`，以及应用了本仓库补丁的无限画布与 `@local/dsh-liclick-adapter`。无限画布跟随 latest；当前补丁按宿主实际解析的 0.20.5 生成，保留上游的星标默认模型显示逻辑。pnpm 仅容忍补丁行号约 20 行偏移，不能把 Git 应用成功当作跨版本安装通过；宿主改选版本后须重新检查补丁。Atlas CLI 使用独立 Node 运行，避免 Electron 导致其命令参数解析错误。

打开无限画布 → 设置 → **接入 / 刷新 LiClick 模型**。这一步仅检查登录与读取模型目录，不提交生成任务。它保留其他供应商和仍有效的默认模型；初次没有默认模型时才选择目录中的首项。登录失效时先在终端执行 `atlas-skillhub gateway login`，再重新连接。

模型直接来自 `generate_image` / `generate_video` 的实时目录，不按品牌白名单过滤。2026-11-03 的目录包含 **11 个图片模型与 14 个视频模型**：图片包括 Seedream、GPT-Image 2 / 2.5 Sunburst / 2.5 Flare、Nano Banana 2 / 2.1 / Pro、Midjourney；视频包括可灵、MiniMax-H3、Gemini Omni、Seedance、Vidu 和四个视频增强模型。模型上下线后使用刷新按钮更新，真实服务仍负责最终权限与参数校验。

图片尺寸、比例、视频分辨率与时长按模型目录适配。例如 H3 使用 `768P/2K`，Vidu Q3 的时长是 `4/8/12/16`，GPT 的 `auto` 比例与 `auto` 尺寸联动。未提供某项参数的模型会禁用相应控件。模型切换时使用其有效默认值；连接分镜表给出的时长不会静默缩短，超出模型上限会报错。

首尾帧可通过节点扩展参数 `request_type: "first_last_frame"` 指定，需模型支持且恰好两张图。视频增强模型必须将一个原视频连接到参考输入，不能用截图代替；支持视频参考的生成模型也会上传真实视频。当前仍使用 LiClick 个人工作区，不包含 3D、音乐和共享工作区适配。

在图片或视频节点选择模型、填写提示词并点击生成即可。节点扩展参数只接受该模型已声明的参数；声音等未显式覆盖的选项遵循模型默认值。Midjourney 每批固定四张，数量控件和模型名称会标明这一点，四张结果全部导入画布资产与历史，不只保留第一张。

## 实现边界

- 通过原有 CLI 调用 `list-tools`、`upload_asset`、`generate_image`、`generate_video` 和 `get_task_status`，不复制或读取 Atlas OAuth 缓存中的密钥。
- 复用画布已有的异步任务协议（设置中显示 Sanbao 格式），实际请求全部发往本机 LiClick 适配层，不使用三宝账号或服务。
- 适配层仅监听 `127.0.0.1`，使用独立随机凭据。端口、凭据、任务和上传映射保存在各 profile 的 `liclick-adapter/` 下，不提交到 Git。其他电脑需要本机登录并再次点击连接，不能复制凭据文件。
- 只接收画布上传的本地素材或本适配层的素材引用，不让任意 URL 变成服务端下载请求。每份 HTTP 请求最多 15MB；已声明的图片、视频数量及总素材上限会本地检查，其他约束由 LiClick 最终校验。较大视频仍受画布代理请求大小限制，需要先压缩。
- 每次画布生成有独立请求 ID；相同 ID 的重试不会再次提交，改变请求内容会被拒绝。一般图片逐张生成，Midjourney 按固定四张一批处理；最多同时提交两项任务。结果 URL 列表会完整持久化并随任务查询返回。
- 已获得远端任务 ID 的任务在重启后可继续查询；提交超时或中途退出且没有拿到远端 ID 时，结果视为未知，不自动重发。先在 LiClick 查询，避免重复计费。
- 画布“停止”停止本地等待；当前 LiClick skill 没有取消远端任务工具，因此不能承诺取消已经提交的云端生成或退还额度。

## 维护和验证

无限画布补丁包含公开的 `liclickConfiguration` RPC/服务契约、设置入口、LiClick 请求 ID、模型参数选项和多结果回填。配置由画布自己的代码保存；适配层不操作其他插件的 DOM 或私有存储。新增供应商不会自动提交任务。

0.20.x 上游新增的图片模型桥接（`viaImageGen`）与自动创作/桥接卡片属于上游行为，与本补丁共存在同一设置页：图片生成保留桥接分支，同时保留 LiClick 多结果回填；`flattenImageModels` 的桥接字段与 LiClick 模型元数据一起透传。升级 0.20.x 后需重新应用补丁并核对这两处共存逻辑。

`npm test` 包含协议、鉴权、并发去重、参考上传、重启恢复和 CLI 参数边界测试。对安装了补丁的隔离 `DSH_HOME` 运行 `npm run test:liclick-canvas`，使用实际画布调用代码与模拟网关验证图片、视频、参考素材模式和提交前任务 ID 保存，不消耗生成额度。真实模型目录/登录验证不等于收费生成已成功；真实生成应使用用户明确指定的素材和预算。

升级无限画布时需重新核对补丁、任务协议及配置入口，不应绕过补丁失败。更新本地插件后按仓库安装流程重新打包、隔离安装并检查本机锁文件，再部署；不写回仓库锁模板。

`npm run test:liclick-gateway` 从实际桌面 Electron 进程启动适配器的网关调用，检查登录和实时模型发现，不提交生成任务。
