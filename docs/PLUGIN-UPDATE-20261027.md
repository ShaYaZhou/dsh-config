## 布局修复

sidebar-layout 1.0.1仅负责原生rc.3侧栏底部布局。用量卡片独占整行，紧凑入口两列排列，启动动画的小图标组保持在一个单元格中；折叠状态仍竖向排列。复用已有按钮和点击行为，不读取其他插件状态、不移动DOM，不注册工具、提示或存储。

实际根因是原生footer内存在display: contents的插槽包装层，旧选择器没有命中真正的网格子项。最终在该插槽统一设置网格，未修改用量插件代码；曾尝试的owner.wide适配已撤销。原生结构适配集中在这个插件中，宿主升级必须重验。
