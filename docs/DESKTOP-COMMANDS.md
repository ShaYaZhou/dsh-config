# 桌面端命令入口

命令层复用原生 Session、Agent preset、侧问和快照服务，不把命令作为普通 LLM 提示词实现。本轮只对 desktop profile 增加入口，未把交互命令装进一次性 headless profile。

| 入口 | 行为 |
|---|---|
| `/agents` | 列出持久角色；选择后在新会话中使用；“创建或编辑”进入原生 Creator |
| `/clear` | 创建新的干净上下文，沿用角色，保留原会话 |
| `/resume` | 选择并恢复已有非空会话 |
| `/fork` | 从当前会话创建分支并打开 |
| `/help` | 查看命令目录；选择条目只填入输入框，等待用户执行 |
| `/btw 问题` | 原只读旁问气泡，保留连续旁问历史 |
| `/rewind` | 原消息选择器和回退确认界面 |
| `/model`、`/plan`、`/permission`、`/compact`、`/review` | 继续使用原生或既有插件入口 |

Rewind 使用未修改的上游 0.19.2，保留上游消息旁入口和 `/rewind` 选择器。旧定制的标题栏 `↶`、参数提示、仅文件回退和额外的恢复结果判定已移除；操作能力以原版界面为准。既有快照和历史不清理。

桌面端的窗口关闭按钮通常将应用隐藏到托盘，**不退出后台进程**。安装后应从应用菜单或系统托盘选择“退出”，再重新启动；只点 X 再打开窗口可能继续使用旧模块。不要为更新插件强行终止仍在运行的任务。

该命令适配是新的独立本地 UI 包；Rewind 原版独立提供回退功能。客户端 JS 同样纳入 status/capture 哈希管理。`clean` 原生恢复会卸载这些增强；会话和记忆数据保留。
# 会话删除入口

删除由 Archive Manager 提供，自写 `@local/dsh-delete-session` 已移除，避免同一菜单出现两个同名入口。Archive Manager 的删除是永久删除；希望保留恢复能力时使用“归档会话”。卸载自写插件不清理已有会话、历史或旧回收目录。

在 0.2.2-rc.1 桌面复验中，上游 Archive Manager 1.2.7 冷启动后可能缺少删除菜单项；当前保留原版，等待上游兼容修复，不注入菜单补丁。
