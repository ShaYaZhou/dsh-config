# Proposal

## Why

用户明确禁止写记忆时，后台摘要仍会写入 rollout 和工作区摘要。独立嵌套会话也没有继承这个边界，不能只靠模型遵守提示。

## What Changes

- 在记忆插件内统一判断用户的直接禁写要求，保护自动摘要、摘录、合并和记忆写工具。
- 嵌套会话通过公开接口记录父会话关系，写入时继承限制；恢复会话后仍生效。
- 已启动的后台摘要提交前重新检查，禁止内容不进入后续合并。
- 保留正常会话的自动记忆与只读查询，并进行真实桌面验收。

## Capabilities

### New Capabilities
- `session-memory-write-policy`: 用户控制的会话级长期记忆写入边界及父子继承。

### Modified Capabilities
无。

## Impact

记忆插件、嵌套会话创建入口、回归测试、来源记录与使用文档。无新增依赖；不提交真实记忆、会话或本机截图补丁。
