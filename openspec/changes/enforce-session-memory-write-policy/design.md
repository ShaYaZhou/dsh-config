# Design

记忆插件拥有禁写判断；直接用户消息从原始会话事件读取，忽略模型、工具和引用文本。约束持续至会话生命周期结束，避免后续回填先前禁止的内容；新建正常会话仍可使用记忆，不增加隐式恢复开关。

父子关系通过记忆插件公开的 `memoryWritePolicy.inherit(parent, child)` 和可忽略插件记录传递；写入时沿公开会话查询检查父会话，禁止导入嵌套插件的私有存储。原生 parentSession 与已有 relay 消息用于兼容旧会话。读取失败、关系循环按禁止处理。

自动生成前检查、锁内提交前复查；consolidation 携带触发它的会话，不能丢失来源。显式记忆写工具复用同一检查，并在锁内重查。只读工具可以读取已有文件，禁写时跳过具有写副作用的作用域初始化。全局启动维护和其他正常会话不因一个会话被整体关闭。

验证覆盖主会话、提示省略禁令的子会话、冷读、fork/subagent、消息来源信任、运行中撤销和正常正对照；实际桌面发送任务并用存储哈希复核。真实数据和本机控制组件修复不进入仓库。
