# M01 卷积核网格对照

同一张输入经几个卷积核后的输出并排对照，讲模糊、描边、锐化时用。替换数值与三组标题、输出标签；增减核时复制一组（核、箭头、输出、标签）。换输入后，三组输出及底色深浅 `--v` 都要重算：`--v` = 该格绝对值 ÷ 该组最大绝对值，每组各自归一化。页脚“格里数字是该像素的灰度”只适用于输入，输出格要另写页脚。示例内容只是占位，使用时整套换成用户的内容，包括标题、副标题、标签、页脚和一句话概述。
