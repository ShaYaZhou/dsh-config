# M02 展平示例

把 3×3 输入和 2×2 核按行压成列向量并标出下标，讲卷积前的数据整理时用。这里的“卷积”指不翻转核的互相关（深度学习框架通用做法）；若要用翻转核的卷积，结果会不同。替换数值与组标签；改尺寸时同步改下标、组标签和列数（.fx-m02-c2、.fx-m02-c4）；卷积核的格用焦点边框标出。示例内容只是占位，使用时整套换成用户的内容，包括标题、副标题、标签、页脚和一句话概述。
