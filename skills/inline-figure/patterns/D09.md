# D09 漏斗条

有先后承接关系的 3 到 7 个阶段，每一步还剩多少，条长按占首阶段的比例；阶段彼此独立时改用排行柱图。改数据改各行的条宽（写成 max(12px, 比例%)；比例为 0 的阶段不放条元素，读数仍写 0.0%）与读数，增减阶段就增减行，并同步改连接符。焦点是最后一阶段，条色与阶段名字色共同标出。示例内容只是占位，使用时整套换成用户的内容，包括标题、副标题、标签、页脚和一句话概述。
