# M05 连续卷积多帧

讲连续卷积时用，两个方块相卷，看重叠面积随平移变化。替换标题、副标题与每帧的 x 值和面积；重叠区用焦点色填充，三角折线是唯一的焦点线。帧数固定为四，增减帧时同步改 .fx-m05-grid 的列数并复制对应帧。示例内容只是占位，使用时整套换成用户的内容，包括标题、副标题、标签、页脚和一句话概述。

```css

@container (min-width:620px){.fx-m05-grid{grid-template-columns:repeat(4,minmax(0,1fr))}}

.fx-m05-lg{display:inline-flex;align-items:center}
@container (max-width:619px){.fx-m05 .fg-foot{column-gap:var(--sp-4)}}
```
