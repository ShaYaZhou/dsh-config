# HTML Course 设计准则

HTML Course 只在用户明确同意后制作。它是教学内容的复习与练习载体，不是教学发生的前提。

## 一、结构原则

- 复用已有课程网站；存在唯一网站时不得另建平行站点。
- 首页清楚展示学习地图、当前位置、前置条件和阶段成果。
- 单课只解决一个主要问题，并提供一个可观察的学习成果。
- 主线内容连续可读，L2-L4 深水内容渐进展开。
- 每课提供上一课、下一课、课程地图和复习入口。
- 进度与完成状态不能冒充掌握程度。

## 二、单课页面

建议顺序：

```text
标题、课次、预计时间、深度
→ 本课成果
→ 前课提取
→ 现实问题
→ 中英术语
→ 核心直觉与准确机制
→ 示例、反例与互动练习
→ 可选面试题
→ 无笔记复述与评分
→ 课后笔记与延迟复习
```

长内容应切分为短节，保持明显的小标题和当前位置。深水内容可折叠，但不能隐藏必学主线。

## 三、视觉与交互

- 面向学习工具，使用安静、清晰、可扫描的布局；
- 桌面端可使用固定课程导航，移动端使用可展开目录；
- 正文保持舒适行宽与行距，避免超大标题挤压内容；
- L1-L4 使用颜色与文字双重标识；
- 练习、提示、答案和错误反馈有明确状态差异；
- 不使用卡片套卡片，不靠装饰性渐变、光球或大面积营销 Hero；
- 控件尺寸稳定，动态内容不得造成布局跳动；
- 支持键盘操作、可见焦点和 `prefers-reduced-motion`；
- 所有文字在桌面和移动端都不得溢出或互相遮挡。

## 四、AIPath 可借鉴部分

- 对零基础用户友好的课程地图；
- 清楚的课次与进度；
- 直觉解释先于复杂原理；
- 每课范围有限，阅读节奏稳定；
- 视觉层级持续一致；
- 从基础概念逐步推进到应用。

需要改进并纳入 Aisland 方法：

- 明确 L1-L4 深度；
- 加入中英术语和比喻边界；
- 增加主动回忆、复述评分和延迟复习；
- 让产品、评测、权限与真实任务更早进入；
- 区分稳定原理与会过时的产品新闻；
- 保留讲授者真实困惑、失败和修正。

只提炼原则，不复制 AIPath 的文案、代码、视觉资产和具体页面构图。

## 五、验收

- 页面与课程地图中的编号、标题和前置关系一致；
- 所有导航和链接有效；
- 练习、答案、复述和本地笔记可以正常使用；
- 桌面与移动端无横向溢出和遮挡；
- 浏览器控制台无错误；
- 不保存真实密钥或个人敏感信息；
- 事实和外部资料有来源，引用边界清楚。
