# 教学原则

## 1. 学习目标必须可观察

把“理解”“熟悉”改成可以验证的动作：解释、比较、预测、修复、设计、实现或迁移。课程覆盖了什么不等于用户学会了什么。

## 2. 从零基础开始，但不降低终点

- 先识别隐藏前置知识；
- 先讲现实问题，再引入术语；
- 先给直觉模型，再补充精确边界；
- 复杂内容分层展开，不一次倒给用户。

零基础是一条路径设计要求，不是把内容永久停留在浅层。

## 3. 最近发展区

任务应略高于用户独立完成能力，但能在有限提示下完成。

- 完全不会：补前置知识；
- 提示后会：当前合适难度；
- 无提示稳定完成：可以进入下一层；
- 只会复述原句：尚未形成迁移能力。

## 4. 流畅感与长期记忆

听懂当下形成的是流畅感。长期记忆需要：

- Retrieval Practice：主动从记忆中提取；
- Spacing：在第 1、3、7 天重新提取；
- Interleaving：掌握基础后混合相近问题；
- Generation：先预测或尝试，再看答案；
- Feedback：尽快获得具体纠错。

知识获取阶段降低无关难度；技能练习阶段加入适度困难。

## 5. 中英双语术语

- 第一次出现时写成“中文（English）”；
- 说明术语在该领域的准确含义；
- 后续保持一致，不频繁更换译法；
- 必要时说明英文文档常见的别名和歧义。

双语术语服务论文、文档和工作沟通，不做单纯词汇表堆积。

## 6. 比喻必须有边界

一个好比喻需要同时说明：

1. 它帮助理解哪种关系；
2. 哪些机制没有被比喻覆盖；
3. 在哪里继续使用会产生误导。

## 7. 可信知识

- 优先一手资料、官方文档、论文和公认教材；
- 把新闻与稳定原理分开；
- 标注更新时间和不确定性；
- 不用一条案例证明普遍规律；
- 对关键事实保留可追溯来源。

## 8. 教学证据

可靠性从低到高大致为：

```text
看过
→ 能识别
→ 能无笔记解释
→ 能比较与判断
→ 能在新场景应用
→ 能发现错误并自我修正
```

学习记录只提升到已有证据支持的层级。
