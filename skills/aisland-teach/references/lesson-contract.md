# Aisland 单课教学契约

这是可调整的教学骨架，不是每次必须完整展示的页面模板。

## 一、课前判断

| 检查 | 要回答的问题 |
| --- | --- |
| Mission | 用户为什么需要学它？ |
| Outcome | 结束时能完成什么动作？ |
| Baseline | 用户已经稳定掌握什么？ |
| Dependency | 最靠近目标的缺口是什么？ |
| Scope | 本次只跨越哪个主要认知台阶？ |

## 二、单课顺序

| 顺序 | 环节 | 作用 |
| --- | --- | --- |
| 1 | 本课成果 | 先知道学完能做什么 |
| 2 | 前置检查或前课回顾 | 提取已有知识，发现断层 |
| 3 | 现实问题 | 解释为什么需要这个概念 |
| 4 | 中英术语 | 建立中文直觉与英文资料入口 |
| 5 | 核心直觉 | 用最少概念形成第一版心智模型 |
| 6 | 准确机制 | 补充因果链、结构和边界 |
| 7 | 例子与反例 | 识别适用条件和失败方式 |
| 8 | 主动练习 | 预测、判断、操作或迁移 |
| 9 | 错误诊所 | 修正最可能出现的误解 |
| 10 | 复述评分 | 无笔记重建理解并反馈 |
| 11 | 课后笔记 | 压缩为可复习材料 |
| 12 | 延迟复习 | 为第 1、3、7 天留下问题 |

短教学可以压缩环节，但不能省略学习结果、准确解释和理解检查。

## 三、深度分层

| 层级 | 名称 | 目标 | 内容边界 |
| --- | --- | --- | --- |
| L1 | 浅水区 | 所有初学者建立正确直觉 | 一句话解释、核心关系、现实用途 |
| L2 | 应用区 | 能在任务中使用 | 操作方法、案例、常见错误 |
| L3 | 深水区 | 产品与工程理解 | 机制、系统结构、约束与评测 |
| L4 | 潜航区 | 研究与高级工程入口 | 论文、数学、源码与开放问题 |

- 所有人必须走通 L1；
- L2-L4 按 Mission 和最近发展区展开；
- 层级必须同时使用文字标签，不能只靠颜色表达。

## 四、企业面试题的使用条件

只有满足以下任一条件时才加入：

- 主题直接服务 AI、技术、产品或职业迁移；
- 面试题能检验因果理解，而非背诵定义；
- 用户明确准备面试或职业表达。

优先问题类型：

- 比较两个容易混淆的概念；
- 解释一次设计取舍；
- 分析一个失败案例；
- 把知识迁移到真实业务。

## 五、课后笔记

默认保持一屏左右：

```markdown
# 主题

## 一句话

## 核心机制

## 中英术语

## 一个例子

## 容易错在哪里

## 我的复述

## 下次复习问题
```

笔记用于提取线索，不复制整堂课。
